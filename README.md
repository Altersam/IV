# Новая архитектура профильного образования
## От академической базы к инновациям — Лицей Финансового университета

В архиве 34 интерактивных слайда, 21 локальных изображений, логотип и офлайн-галерея.

## Как открыть
1. Распакуйте весь ZIP в одну папку.
2. Откройте index.html (подключение к интернету не требуется).
3. Для GitHub Pages загрузите содержимое архива в корень репозитория; откройте index.html.

## Управление
Перелистывание: кнопки **← / →** в нижнем правом углу или клавиши стрелок **влево / вправо**. Прочие элементы слайдов не требуют нажатия. Анимация схем, карточек и диаграмм запускается при появлении каждого слайда. Колёсико, клик по карточкам и свайпы не переключают слайды.

## Цветовая система
Спокойная голубо-бирюзовая палитра, тонкая типографика, открытая подача полноразмерных фотографий и схем. Подписи к фотографиям размещены отдельно от самих изображений.

## Структура
- index.html — главный файл презентации.
- Новая_архитектура_профильного_образования.html — копия index.html.
- gallery.html — отдельная галерея всех изображений.
- assets/photos/ — все оригинальные WebP, включая архивные снимки, планы и концептуальные визуализации.
- assets/brand/ — официальный исходный логотип из репозитория LFU.
- assets/fonts/ — локальные шрифты для автономного просмотра, если загрузка доступна.
- SOURCES.csv — происхождение каждого изображения.
- speaker_notes.md — заметки к слайдам.
- standalone.html — автономный HTML со встроенными изображениями и шрифтами.
- previews/ — статичные предпросмотры всех 34 слайдов для быстрого просмотра.

## Важно
Проектные визуализации (здание, лаборатория ИИ, Т1) НЕ являются документальными фотографиями готового пространства. Подписи это отражают. Для публичного распространения правовой статус исходных изображений следует проверить.
